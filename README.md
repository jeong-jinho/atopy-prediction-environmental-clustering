# 환경 요인 기반 아토피 발현 예측 — 개인별 민감도 클러스터링

> 세분화가 능사가 아니라는 걸 확인하고, "더 잘게 쪼개기" 대신 "여러 요인을 조합하기"로 방향을 바꿔 예측 성능을 상대적으로 약 15~20% 개선한 프로젝트

`시계열` `환경데이터` `조합 클러스터링` `XGBoost`

>  이 프로젝트는 **비공개데이터**를 사용했습니다. 원본 데이터, 정확한 표본 수, 환자 식별 정보, 세부 수치는 공개하지 않으며, 문제 해결 과정과 인사이트 위주로 정리했습니다. 코드와 원본 데이터도 이 저장소에는 포함하지 않습니다.

## 문제 정의

아토피피부염은 온도·습도·실내공기질·외부대기오염 등 환경 요인의 영향을 받는다고 알려져 있지만, **모든 환자가 같은 요인에 똑같이 반응하지는 않습니다.** 어떤 환자는 온도에 민감하고, 어떤 환자는 특정 대기오염물질에 더 민감할 수 있습니다.

이 프로젝트는 전체 환자를 하나의 모델로 뭉뚱그려 예측하는 대신, **환자마다 가장 강하게 반응하는 환경 요인이 무엇인지를 먼저 파악하고, 비슷한 민감도 패턴을 가진 환자끼리 묶어 예측 성능을 높일 수 있는지** 검증하는 것을 목표로 했습니다.

## 접근 방법

**0단계 — 개인별 모델링 시도 (선행 탐색)**
클러스터링 이전에, 환자 개인 단위로 회귀·분류 모델을 직접 학습시키는 방식부터 시도했습니다. 당일 환경정보, 1일 지연(lag), 1~7일 다중 지연 등 다양한 피처 구성을 시도했지만, 환자 한 명당 확보되는 데이터가 워낙 적어 성능이 전혀 안정되지 않았습니다. 회귀에서는 설명력 지표가 음수로 나오는 경우가 흔했고, 분류로 바꿔도 특정 클래스에 예측이 쏠리는 문제가 반복됐습니다. 남녀를 나눠서 각각 모델링해봐도 큰 개선은 없었고, 환자 단위로 성능을 뜯어보면 표본이 적은 환자일수록 지표가 극단적으로 불안정했습니다. 이 과정에서 "개인 단위로는 통계적으로 안정된 모델을 만들기 어렵다"는 게 명확해졌고, 이게 클러스터링 접근으로 전환하게 된 계기가 되었습니다.

**1단계 — 상관계수 산출 방식 비교**
환자별로 환경 요인과 발현 지표 간 상관계수를 구하는 세 가지 방식을 팀원들과 각자 비교했습니다. 세 방식 모두 상위 순위는 거의 동일했지만, 상관계수 값 자체는 한 방식이 전반적으로 조금 더 높게 나와 이후 분석은 그 방식을 채택했습니다.

**2단계 — 클러스터링 단위를 단계적으로 조정**
환자를 "가장 상관계수가 높은 환경 요인"이 무엇인지로 그룹화하되, 그룹을 나누는 단위를 바꿔가며 비교했습니다.

| 클러스터링 방식 | 결과 (상대 비교) |
| --- | --- |
| 개별(1등 요인 그대로) | 그룹당 인원이 너무 적어 개별 분석과 큰 차이 없음, 성능 낮음 |
| 대분류(온도/습도/실내공기질/외부대기오염) | 가장 좋은 그룹(온도)이 가장 낮은 그룹(외부대기오염) 대비 **성능 지수 약 1.6배** — 요인별 편차가 뚜렷함 |
| 세분류(개별 오염물질 단위) | 대분류보다 더 세분화했지만 뚜렷한 개선 없음 |
| 2개 요인 조합 클러스터 | 대분류 최고 성능 대비 소폭(한 자릿수 %대) 개선 |
| 3개 요인 조합 클러스터 | 대분류 최고 성능 대비 **약 15~20% 개선** — 가장 높은 성능을 보인 조합 발견 |

모델은 XGBoost를 사용했고, train/test는 **환자 단위로 그룹 분할**해 train에 없던 환자만 test에 들어가도록 설계해 데이터 누수를 방지했습니다.

**3단계 — 최고 성능 그룹들의 실체 확인**
성능이 가장 좋았던 상위 조합들이 혹시 **같은 환자들이 이름만 바뀌어 재등장**한 결과는 아닌지 의심스러워, 그룹 간 환자 구성을 직접 대조했습니다.

## 주요 의사결정 & 트러블슈팅

### 개인별 모델링의 한계를 정량적으로 확인
회귀 R², 분류 accuracy/F1을 환자 단위로 쪼개서 봤을 때, 표본이 적은 환자일수록 지표가 극단적으로 튀는(때로는 수치적으로 발산하는) 현상을 확인했습니다. 이는 "모델이 나쁘다"기보다 "환자 1명당 평가에 쓸 데이터가 근본적으로 부족하다"는 구조적 문제였고, 이 확인 과정이 있었기 때문에 이후 그룹 단위 접근으로 방향을 바꾸는 근거가 명확해졌습니다.

### 세분화가 능사는 아니라는 발견
클러스터를 더 세분화하면 더 정교해질 거라 예상했지만, 실제로는 성능이 개선되지 않았습니다. 그룹을 잘게 쪼갤수록 그룹당 데이터 수가 줄어 오히려 학습이 불안정해지는 트레이드오프가 있다는 걸 확인했고, 이를 계기로 "더 잘게 쪼개기"가 아니라 "여러 요인을 조합해서 그룹을 재구성하기"로 방향을 바꿨습니다. 이 전환이 실제로 성능 개선으로 이어졌습니다.

### "숫자가 좋아 보여도 직접 눈으로 확인" — 그룹 간 환자 중복 검증
성능이 좋았던 두 조합 그룹 모두 높은 성능을 보였을 때, 이게 혹시 같은 환자들이 여러 조합에 중복으로 걸려 나온 착시는 아닌지 의심하고 두 그룹의 환자 구성을 직접 대조했습니다. 결과적으로 중복은 낮은 수준이었고, 이는 서로 다른 환경 조합이 실제로 다른 환자 서브그룹을 포착하고 있다는 근거가 되었습니다.

### 회귀 → 이진 분류로 타겟을 바꾼 이유
개인별 분석에서는 연속형 점수(증상 총점)를 그대로 예측하거나 여러 구간으로 나눈 다중 클래스로 분류했는데, 두 방식 다 성능이 낮았습니다. 클러스터링 분석에서는 "증상 발현 여부"를 임상적 기준(주관적 증상 점수와 객관적 징후를 함께 고려한 정의)에 따라 미리 이진화해둔 변수를 타겟으로 사용했고, 이 쪽이 훨씬 안정적인 성능을 보였습니다. 문제를 어떻게 정의하느냐(연속값 회귀 vs 다중 클래스 vs 임상적으로 의미 있는 이진 분류)가 결과에 큰 영향을 미친다는 걸 확인한 지점입니다.

## 결과

- 개인별 회귀/분류: 표본 부족으로 근본적으로 불안정 — 성능 이전에 평가 자체가 신뢰하기 어려움
- 개별/세분화 클러스터링: 뚜렷한 개선 없음
- 대분류 클러스터링: 최상위 그룹(온도)이 최하위 그룹(외부대기오염) 대비 **성능 지수 약 1.6배** — 요인에 따라 예측 난이도 편차가 뚜렷함을 확인
- 3요인 조합 클러스터링: 대분류 최고 성능 대비 **상대적으로 약 15~20% 추가 개선**, 전체 실험 중 최고 성능
- 최고 성능 상위 두 그룹 간 환자 중복률: **한 자릿수 %대**로 낮음 — 서로 다른 환경 조합이 실제로 다른 환자군을 반영함을 확인

> 절대 수치(정확도 값, 표본 수 등)는 비공개 데이터 특성상 공개하지 않고, 위와 같이 상대 비율로 치환해 정리했습니다.

이 프로젝트는 비공개 임상 데이터를 사용했기 때문에, 다른 프로젝트와 달리 **코드(`src/`)와 결과 데이터(`results/`)를 이 저장소에 포함하지 않습니다.** 위 내용은 실제 분석 과정에서 거친 시행착오와 의사결정을 정리한 것입니다.
