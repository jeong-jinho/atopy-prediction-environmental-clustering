# 환경 요인 기반 아토피 발현 예측 — 개인별 민감도 클러스터링

> 세분화가 능사가 아니라는 걸 확인하고, "더 잘게 쪼개기" 대신 "여러 요인을 조합하기"로 방향을 바꿔 정확도를 0.71 → 0.83으로 개선한 프로젝트

`시계열` `환경데이터` `조합 클러스터링` `XGBoost`

## 문제 정의

아토피피부염은 온도·습도·실내공기질·외부대기오염 등 환경 요인의 영향을 받는다고 알려져 있지만, **모든 환자가 같은 요인에 똑같이 반응하지는 않습니다.** 어떤 환자는 온도에 민감하고, 어떤 환자는 특정 대기오염물질에 더 민감할 수 있습니다.

이 프로젝트는 전체 환자를 하나의 모델로 뭉뚱그려 예측하는 대신, **환자마다 가장 강하게 반응하는 환경 요인이 무엇인지를 먼저 파악하고, 비슷한 민감도 패턴을 가진 환자끼리 묶어 예측 정확도를 높일 수 있는지** 검증하는 것을 목표로 했습니다.

---

## 접근 방법

**1단계 — 상관계수 산출 방식 비교**
환자별로 환경 요인과 발현 지표 간 상관계수를 구하는 세 가지 방식을 비교했습니다. 세 방식 모두 1~5등 순위는 거의 동일했지만, 상관계수 값 자체는 첫 번째 방식이 전반적으로 조금 더 높게 나와 이후 분석은 첫 번째 방식을 채택했습니다.

**2단계 — 클러스터링 단위를 단계적으로 조정**
환자를 "가장 상관계수가 높은(1등) 환경 요인"이 무엇인지로 그룹화하되, 그룹을 나누는 단위를 바꿔가며 비교했습니다.

| 클러스터링 방식 | 그룹 수 | 결과 |
| --- | --- | --- |
| 1등 요인 그대로(개별) | 다수(대부분 4명 이하) | 개별 분석과 큰 차이 없음, 정확도 낮음 |
| 4개 대분류(온도/습도/실내공기질/외부대기오염) | 4 | 온도 그룹 0.71로 양호, 습도 0.48로 저조 |
| 9개 세분류(개별 오염물질 단위) | 9 | 세분화해도 뚜렷한 개선 없음 |
| 2개 요인 조합 | 36(₉C₂) | O3&SO2 조합 0.67로 개선 |
| 3개 요인 조합 | 84(₉C₃) | **CO&PM2.5&HCHO 조합 0.83으로 최고 성능** |

모델은 XGBoost를 사용했고, train/test는 **환자 ID 단위로 그룹 분할**해 train에 없던 id만 test에 들어가도록 설계해 데이터 누수를 방지했습니다.

**3단계 — 최고 성능 두 그룹의 실체 확인**
가장 성능이 좋았던 두 조합(`CO&HCHO&PM2.5`=0.83, `CO2&HCHO&O3`=0.74)이 혹시 **같은 환자들이 이름만 바뀌어 재등장**한 결과는 아닌지 의심스러워, 두 그룹의 환자 ID를 직접 대조했습니다.

## 주요 의사결정 & 트러블슈팅

### 세분화가 능사는 아니라는 발견
클러스터를 4개에서 9개로 세분화하면 더 정교해질 거라 예상했지만, 실제로는 성능이 개선되지 않았습니다. 그룹을 잘게 쪼갤수록 그룹당 데이터 수가 줄어 오히려 학습이 불안정해지는 트레이드오프가 있다는 걸 확인했고, 이를 계기로 "더 잘게 쪼개기"가 아니라 "여러 요인을 조합해서 그룹을 재구성하기"로 방향을 바꿨습니다. 2개 조합(36가지)과 3개 조합(84가지)을 전수 비교하는 방식으로 전환한 게 실제로 정확도 개선(최대 0.83)으로 이어졌습니다.

### "숫자가 좋아 보여도 직접 눈으로 확인" — ID 중복 검증
CO&PM2.5&HCHO 그룹(17명)과 CO2&HCHO&O3 그룹(20명) 모두 높은 정확도를 보였을 때, 이게 혹시 같은 환자들이 여러 조합에 중복으로 걸려 나온 착시는 아닌지 의심하고 두 그룹의 환자 ID를 직접 대조했습니다. 결과적으로 **두 그룹 사이의 중복 환자는 단 2명(043, 116)** 뿐이었고, 이는 두 환경 조합이 실제로 서로 다른 환자 서브그룹을 포착하고 있다는 근거가 되었습니다.

## 결과

- 개별/9개 세분류 클러스터링: 뚜렷한 개선 없음
- 4개 대분류: 최고 0.71 (온도 민감 그룹)
- 3개 요인 조합: **최고 0.83 (CO·PM2.5·HCHO 민감 그룹, 17명)**
- 최고 성능 두 그룹 간 환자 중복률 약 5.7%(2/35명) — 서로 다른 환경 조합이 실제로 다른 환자군을 반영함을 확인
